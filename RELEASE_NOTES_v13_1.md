# Nosework Run Board — v13.1

Local demo validated November 13, 2026; uploaded to GitHub November 14, 2026.

## Changes since v9
- Administrator overview activation and paired runs; double-confirmation event deletion.
- Parking Lot Steward on-deck list, next eligible dog and staging call slot released automatically by Gate Steward dispatch.
- Separate sent, run-order complete and Admin-confirmed Done states; correct configurable on-deck counts.
- Stable dog identity during roster edits and complete trial-day reset without losing configuration.
- Compact mobile header, operational colors and accessible steward station navigation (v13.1 hotfix).

## Validation and limitations
Saved local regression report records Chromium checks at 320, 360, 390, 768 and 1280 px, with no overflow or JavaScript page errors, plus staging, hold/resume and reset checks. Physical-device acceptance and live load testing remain pending.

Open index.html locally in a current web browser. This is an offline prototype, not an authenticated production application. PHP/MySQL persistence, multi-device synchronization, real SMS and Bluehost deployment remain outstanding. No additional recurring costs are authorized.
